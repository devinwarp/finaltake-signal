# FinalTake Signal: PRD and build plan (hackathon, Sun 27 Sep 2026)

**One-liner:** Oriane sees what creators say and show about a market. FinalTake turns the need into a creator brief and a test ad.
**Close line:** Oriane sees what the market is saying. FinalTake turns it into what you test today and what your creators shoot tomorrow.

Event: Oriane x Replit hackathon, SAVVA All Day Lounge, Jumeirah. Hack 12:00-16:00, submit 16:00, demos 16:30, winners 17:30.
Judges: Thibaut Hadjean (Oriane), who wants the video-intelligence layer pushed hard. Amal Jeljeli (YKONE GCC, influencer agency), who asks whether agencies would want it; don't show AI as a creator replacement. Abdulrahman Aldhalaan (Replit), who wants a real product, deployed.

## 1. What the data says (frozen 27 Sep 08:40, see HERO.md)

- **Hero need:** "In heat, sweat forces constant reapplying, and runs sunscreen into your eyes."
- **Volume:** 88 videos, 75 independent creators, 9.06M views, median 21K views.
- **Sample:** 952 sunscreen videos (transcript mentions sunscreen/SPF/sunblock); creators with 5k+ followers; TikTok + Instagram; 27 Jun-27 Sep 2026; paid/partner posts removed.
- **Heat vs general:** heat/sweat conversations raise it 12.1% (56/462); general sunscreen talk 7.1% (36/507).
- **By brand:** Beauty of Joseon 7.7%, Neutrogena 6.3%, Nivea Sun + Skin1004 8.9%. **Framing is category-wide. Do NOT claim a competitor gap.**
- **Proof clip:** @aaliyahpau (TikTok, 1.0M views) at ~0:42 says "since you're sweating more, you're going to need to reapply sunscreen more often"; her caption doesn't mention it. Not an ad (checked). Confirm the exact second.
- **Product for the Approve-angle step:** Beauty of Joseon Matte Sun Stick. Claims are in `data/cache/benefits.json` and unverified until checked.
- **Limits to state if asked:**
  - Oriane account-location data is nearly empty for the UAE, so this is not a UAE-only sample.
  - Extraction is rule-based on transcripts, and every quote is verbatim.

## 2. Users and job

- **Primary user:** agency strategist or creative lead writing briefs for consumer brands.
- **Secondary user:** brand or performance marketer.
- **Job to be done:** "Show me a need creators keep raising, prove it with real videos, and give me a brief my creators can shoot and an ad I can test."

**Non-goals today:** licensing or rights, permit checks, ads-platform integrations, payouts, multi-brand workspaces, pricing screens, rising-trend detection, and live video rendering as a dependency.

## 3. Screens and requirements

**Flow:** Search → Need Board → Evidence → Approve angle → Creator brief + Test ad

| ID | Screen | Requirement |
|---|---|---|
| FR-1 | Search | Brand + competitors + category inputs, prefilled with the cached run (Beauty of Joseon / Neutrogena / Nivea Sun + Skin1004 / sunscreen in heat). Optional "Run live" button: calls Oriane with a 10-second timeout, then falls back to cache with a visible "served from cache" note |
| FR-2 | Need Board | Decision cards read from `data/cache/clusters.json` + `hero-stats.json`. The hero card shows: the need in creators' words; 75 independent creators; 88 videos; median views; heat 12.1% vs general 7.1%; by-brand shares; the sampling-limits line; the framing tag "category-wide need" |
| FR-3 | Need Board | Show up to 2 supporting needs (from `clusters.json`), each labelled with its own counts. Competitor names shown as "Brand B" unless a private toggle is on |
| FR-4 | Evidence | For the hero: list of videos from `statements.json` (theme `sweat_reapply`) joined to `videos.json`: thumbnail/link-out, the verbatim quote highlighted, transcript timestamp if present, date, views, creator handle, language. `dir="auto"` on quotes. Sort by views or date |
| FR-5 | Evidence | Proof-clip card from `proof-clip.json`: what they said, what the caption said, link at the timestamp |
| FR-6 | Approve angle | Shows only `verified: true` claims from `benefits.json` and the `never_claim` list. The user ticks one benefit that answers the need; the brief and ad unlock only after approval |
| FR-7 | Creator brief | Objective; talking points paraphrased (not verbatim) with links back to evidence; visual references; scene sequence; creator profile to hire; claims to avoid; brand-safety notes; creative freedom. Printable HTML |
| FR-8 | Test ad | Storyboard from `data/cache/storyboard.json` + `public/hero-ad.mp4`, captioned "AI-generated presenter, concept prototype, not the campaign". Never plays for a different need or an edited brief |
| FR-9 | All | "Powered by Oriane" credit; counts computed in code from cached JSON, never by an LLM |

**Non-functional requirements:**
- **Portability:** Next.js (App Router, TypeScript, Tailwind); no database and no native modules; data read from committed JSON; keys from env vars.
- **Replit:** no Replit DB, Auth or Storage. Deploy an empty shell by 12:15 and enter Deployment Secrets by hand.
- **Resilience:** the whole demo runs from cache with the network off.
- **FinalTake:** called only from the laptop scripts (`scripts/finaltake-*.mjs`), never from the app or the browser. Its API has no CORS headers.
- **Compliance:** link out to videos, never re-host them; no competitor names or logos in generated creative; the AI presenter never speaks a creator's verbatim quote.

## 4. Data files (`data/cache/`)

| File | What it is |
|---|---|
| `videos.json` | 2,156 cleaned videos: id, url, platform, handle, person key, followers, date, views, likes, caption, hashtags, transcript, language, subjects, paid flag |
| `statements.json` | Verbatim sentences with theme and polarity. The hero theme is `sweat_reapply` (sub-types: reapply, sweat_eyes, wears_off) |
| `clusters.json` | Needs → statement ids (the hero is first) |
| `counts.json` | Per-need counts from `validate.mjs`. Its percentages use all videos as the denominator; **use `hero-stats.json` for on-stage numbers** |
| `hero-stats.json` | Correct hero numbers with sunscreen-only denominators |
| `proof-clip.json` | Primary and secondary proof clips (don't use the secondary @jlin7: it's his own product) |
| `benefits.json` | Product claims to verify, plus the `never_claim` list |
| `manifest.json` | File hashes, freeze time |
| `sun-video-ids.json` | Denominator set |

**Scripts:**
- **Data pipeline:** `csv-to-json` → `clean` → `extract-rules` (or the LLM route: `extract` + `cluster`) → `validate` → `proof-clips` → `freeze`.
- **FinalTake:** `finaltake-token` (run once only) → `finaltake-run tools | storyboard brief.json | render <id>`.

**Judge Q&A:**
- **"Isn't this just what your query looked for?"** The heat set was retrieved on sweat and humidity, so we compare it against general sunscreen talk and show both denominators. The need also shows up at 6-9% for every brand, which is why we call it category-wide.
- **"How is this different from Oriane's Video Analyzer?"** That tool analyses one video. Signal analyses a market across many videos and turns the result into a brief and a test.
- **"Does it replace creators?"** No. The AI ad is a labelled prototype; the brief goes to real creators.
- **"What did you build today?"** The pipeline, the Need Board, Evidence, Approve angle, the brief and the deployment. FinalTake generation is existing infrastructure, called from a script.
- **"Prompt injection via transcripts?"** Transcripts are treated as data only, and every quote must match its transcript word for word.
